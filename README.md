# EGuitarOmitrix

A private electric-guitar practice companion that turns course assignments into a manageable practice queue and a durable record of progress.

**Status:** PRD v0.1, draft for review. This repository contains requirements, research, and delivery conventions. No application, scraper, notation player, score converter, or Guitar Pro integration has been implemented.

## Working agreements

Both human-facing and Agent-facing project documentation are written in **English**. Original Chinese course titles and evidence may remain untranslated where necessary to identify the source. Simplified Chinese learner UI is a provisional product assumption, separate from documentation language.

Use GitHub Issues, Milestones, and pull requests. Every implementation issue must identify its PRD requirements and acceptance criteria. Research completion does not authorize implementation of the researched feature.

Course videos, full transcripts, score files, credentials, and personal practice records stay outside Git. The repository being private does not change that boundary.

Agents should start with [AGENTS.md](AGENTS.md).
