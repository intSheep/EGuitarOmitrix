## Stage-level context

Introductions and outros are guidance, not new per-exercise doses. The source-navigation catalog still exposes every introductory and supporting video. Stage guidance is paraphrased separately in the app; P040 has no independent subtitles. No week-based deadlines or automatic tempo increases are imposed.

## Rebuild

Run `python scripts/build-assignments.py <local-subtitle-directory> <local-video-directory>`. This validates all authored candidate sources and computes their checksums without copying the source package. Content review is offline and no runtime model call is required.
